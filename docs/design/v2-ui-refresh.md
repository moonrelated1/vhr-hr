# 智汇 HRMS v2 界面升级说明

> 适用版本：vhr-hr `feat/ui-refresh` 分支  
> 更新时间：2026-11-23  
> 范围：登录页、应用框架、首页数据看板、员工资料与人事管理模块、演示数据美化

## 1. 背景与目标

系统基于 `lenve/vhr2.0` 二次开发。原始版本员工模块功能完整，但登录页、主框架和列表页仍保留脚手架样式，617 条演示数据存在工号重复、姓名与联系方式雷同等明显痕迹，薪资/统计/系统管理菜单下为空占位页，不适合直接用于课程验收和答辩演示。

v2 的目标是：在**不修改后端业务逻辑、不修改数据库表结构、不改变登录与权限模型**的前提下，完成一套可演示、可截图、可写进报告的专业化界面，并让演示数据在列表、图表、详情和导出中保持一致性。

本次不实现薪资管理、统计管理、系统管理功能，相关空菜单在前端隐藏；员工模块的功能、校验和接口保持不变。

## 3. 页面与交互改造

### 3.1 登录页

- 左右分栏：左侧深蓝品牌区（渐变光晕、价值主张、三个能力点），右侧白色登录卡片。
- 保留原有登录接口和 admin/123 演示账号提示，补充表单校验和加载态。
- 登录失败提示统一由请求拦截器处理，避免重复弹出错误。

### 3.2 应用框架

- 深色可折叠侧边栏，Logo、工作台入口、动态菜单、当前用户和版本信息。
- 白色顶部栏，含折叠按钮、面包屑、日期、用户头像菜单。
- 动态菜单注册后增加兜底路由，修复 F5 刷新子页面被重定向到工作台的问题。
- 页面切换淡入上移，路由变化同步更新浏览器标题。
- 侧边栏仅展示「员工资料」「人事管理」两组；薪资、统计、系统管理不注册路由，直接访问会被重定向到工作台。

### 3.3 首页数据看板

- 顶部问候区、当前日期和快捷操作（新增员工、员工查询、导出档案）。
- KPI：员工总数 617、在职 587、组织部门 13、本月新增 3。
- 图表：部门人数 Top 8、性别结构、学历分布、近 7 年入职趋势。
- 底部：人事记录概览（奖惩 245、培训 410、调动 205、调薪 205）、最近入职 8 人、最新人事动态。
- 数据来源复用现有员工与四类记录接口；前端通过 `loadAllEmployees` 分页并发拉取全量员工，绕开后端单页 100 条上限，未改后端接口。

### 3.4 员工模块

**基本资料 `/emp/basic`**

- 页头、筛选卡片、列表卡片、固定分页的层级结构。
- 列表显示头像、姓名、工号、部门、职位、职级、聘用形式、入职日期、在职状态。
- 操作列统一为「详情 / 编辑 / 删除」，1366px 下不换行、无横向滚动。
- 新增/编辑弹窗按「基本信息 / 岗位与在职 / 合同信息」分组，保留原字段和全部校验；历史脏数据字段只在内容变化时校验。
- 支持 `?action=add` 自动打开新增弹窗。
- 右侧详情抽屉展示基本信息、岗位与任职、教育与合同，可直接编辑或跳转高级资料。
- 按当前筛选条件导出 Excel（27 列，中文表头，文件名 `员工档案_YYYY-MM-DD.xlsx`）。

**高级资料 `/emp/adv`**

- 顶部选中员工资料卡，支持 `?empId=` 自动选中。
- 员工搜索与行点击选人；下方四个标签页嵌入奖惩、培训、调薪、调动记录。
- 记录页在独立访问时显示完整页头和筛选，在高级资料内嵌时只保留表格和新增按钮。

**员工资料与四类记录（人事管理）**

- `/per/emp` 为只读视图，复用员工表格和详情抽屉，不提供编辑、删除。
- `/per/ec`、`/per/train`、`/per/salary`、`/per/mv` 统一为页头 + 筛选 + 表格卡片。
- 奖惩保留奖励绿色、处罚红色的区分；调薪展示调薪前后与涨幅；调动保留「保存后同步更新员工档案」提示。
- 原有 API、远程员工搜索、校验、删除确认和调动事务行为均未改动。

## 6. 运行与演示

```powershell
# 后端（项目根目录）
mvn spring-boot:run

# 前端
cd vhr-vue
npm.cmd install
npm.cmd run dev
```

访问 `http://localhost:5173`，使用 `admin / 123` 登录。数据库连接等本机配置放在 `application-local.yaml`（已 gitignore），不要提交。

推荐演示顺序：登录 → 工作台看板 → 基本资料筛选/详情/新增校验 → 高级资料四个标签页 → 人事管理只读与记录页 → 导出 Excel。

## 7. 范围与限制

- 薪资管理、统计管理、系统管理为后续版本范围，本次仅隐藏菜单，不提供功能，演示时不出现空白页。
- 未修改后端 Java 代码、数据库表结构、菜单表与权限模型。
- 演示数据只用于课程展示；`demo_seed_v2.sql` 会更新 `employee` 及四张记录表，重复执行前会清理 `remark = '演示数据'` 的记录。
- 有奖惩/培训/调动/调薪或薪资账套关联的员工不能直接删除，这是原系统业务约束，v2 保留并在界面中给出明确提示。
